# Working on the app

<AppName /> is a native Android app written in Kotlin, with the UI in Jetpack Compose and
everything stored in a local Room database. It has no backend, no network code and no
analytics, which keeps the codebase small enough to read end to end.

The source is at <RepoLink />, under the GNU GPL v3.

## The stack

| Layer | Choice |
| --- | --- |
| Language | Kotlin, JVM 17 toolchain |
| UI | Jetpack Compose, Material 3, a design system of its own in `:core:ui` |
| Architecture | MVVM over Clean Architecture: domain, data and presentation modules |
| Persistence | Room (SQLite) and Preferences DataStore |
| Dependency injection | Hilt |
| Async | Coroutines and Flow |
| Background work | WorkManager (weekly backup), `AlarmManager` (reminders, rest timer) |
| Navigation | Navigation Compose with type-safe `@Serializable` routes |
| Tests | JUnit, Robolectric, Compose UI tests, Roborazzi screenshot tests with the Accessibility Test Framework, Macrobenchmark |
| Android | min SDK 26 (Android 8.0), target and compile SDK 36 |
