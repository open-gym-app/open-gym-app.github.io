# Brand

The mascot is a dumbbell with a face, standing hands on hips in an orange shirt. It is flat:
three colours, no gradients, no shading. Every file on this page is generated by three scripts
in this site's repository, so the geometry and the colours live in exactly one place.

## Files

This site serves every file: the SVGs under `/brand/svg/`, and PNG exports at common sizes under
`/brand/png/`. Use the SVG wherever you can, and a PNG only where an SVG is not accepted.

| Name | HEX | RGB | Role |
| --- | --- | --- | --- |
| Titan orange | `#FF5A2B` | 255 90 43 | The shirt, the icon field, the energy marks, the wordmark underline. |
| Ink | `#1A1A1A` | 26 26 26 | Limbs, plates, face, keylines; dark backgrounds. |
| Cream | `#FAFAF7` | 250 250 247 | The dumbbell head, the outline; light backgrounds. |

Ink and cream are the app's light-theme `ink` and `paper` (`core/ui/.../theme/Color.kt`). The
orange is the mascot's own, between the UI accent's two values (`#CC4226` light, `#FF6B3D`
dark): keep it in the mascot and the icon, not in the UI, where the accent is tuned for
contrast. For print, get a proof first: screen orange does not survive CMYK unchanged.

## Clear space and minimum size

- **Clear space:** leave at least the height of the dumbbell bar, about a fifth of the
  mascot's height, free on every side. The energy marks above the head count as part of the
  mascot.
- **Minimum size:** the full mascot 48 px or 12 mm tall, the lockup 32 px tall. Below that,
  use `titan-head.svg`, and below 24 px the favicon.

## Do

- Use the outlined mascot on photos and on busy or mid-tone backgrounds.
- Use the one-colour version whenever only one ink is available, not a tinted full-colour one.
- Scale it as a whole.

## Don't

- Recolour the shirt or the head, or add gradients, shadows or glows.
- Stretch, skew or rotate it, or redraw the face with another expression.
- Put the no-outline version on a dark background: the limbs disappear.
- Set "TITAN" in a font next to the mascot. Use the lockup, whose letters are drawn.
- Crowd it inside its clear space, or place it on orange without the outline.

## In the app

The app draws the mark from these files in its repository, all written by `icon.py --app`
and `export.py --app`:

In `app/src/main/res/`:

- `drawable/ic_launcher_foreground.xml`: the adaptive icon's foreground, and the splash
  screen's icon.
- `drawable/ic_launcher_monochrome.xml`: the themed-icon layer for Android 13 and later.
- `values/ic_launcher_background.xml`: Titan orange, the icon's field and the splash screen's
  background.

Elsewhere:

- `core/data/src/main/res/drawable/ic_notification.xml`: the 24 dp status-bar glyph on every
  notification.
- `release/store-assets/titan-play-icon-512.png`: the Play Store listing icon.

The adaptive icon itself, `mipmap-anydpi/ic_launcher.xml`, only names those layers, so it is
written by hand.

## Changing it

The scripts are in `docs/scripts/brand/` in this site's repository. Edit them, never the
generated files: the next run overwrites them. From that directory, with the app checked out
next to this repository:

```bash
python3 mascot.py                          # static/brand/svg/: mascot, head, lockups
python3 icon.py --app ../../../../titan    # static/brand/svg/: icon, favicon, Play icon; the app's drawables
python3 export.py --app ../../../../titan  # static/brand/png/, favicons, the site's logo; the app's Play icon
```

`export.py` needs headless Chromium or Chrome and ImageMagick on the `PATH`. Point the
`CHROME` environment variable at any other Chromium binary, such as Playwright's.
Commit the result in both repositories.
